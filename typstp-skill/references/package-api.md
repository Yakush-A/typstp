# `typo-stp` 0.2.1 — API и поведение шаблона

Пакет: `@preview/typo-stp:0.2.1` (актуальная версия в этом репозитории).
Репозиторий: <https://github.com/Yakush-A/typstp>.

Проверено на Typst 0.15.1.

---

## 1. Подключение

```typst
#import "@preview/typo-stp:0.2.1": *
#show: template
```

`show: template` применяет все `set`/`show`-правила к телу документа. Его
нужно вызывать **один раз и только в главном файле**. Включаемые файлы
(`#include`) не должны повторять `#show: template`.

Модуль `lib.typ` реэкспортирует:

- `src/elements.typ` → `template`;
- `src/functions.typ` → `introduction`, `abstract`, `conclusion`, `appendix`,
  `abclist`, `explanation`, `source-text`;
- `src/constants.typ` (через реэкспорт импортов) → константы;
- `src/pages.typ` → пока пусто (TODO: титульники, листы задания).

## 2. Экспортируемые функции

### `template(body)`

Show-rule. Применяет оформление СТП 01-2024. Принимает тело документа.

### `introduction`, `abstract`, `conclusion`

Готовые заголовки без нумерации (значения-контент, не функции):

```typst
#introduction
Текст введения.
```

Дают заголовки `ВВЕДЕНИЕ`, `РЕФЕРАТ`, `ЗАКЛЮЧЕНИЕ`: уровень 1, без номера,
по центру, прописными, с новой страницы (общее правило уровня 1).

### `appendix(type, name)`

Создаёт приложение как `figure` с `kind: "appendix"`:

```typst
#appendix("обязательное", "Листинг программы") <listing>
```

- `type` — строка внутри скобок: `"обязательное"`, `"рекомендуемое"`,
  `"справочное"`.
- `name` — заголовок приложения.
- Перед приложением делает разрыв страницы.
- Увеличивает счётчик приложений, сбрасывает счётчики рисунков, таблиц и
  формул.
- В тексте печатает `ПРИЛОЖЕНИЕ А`, ниже `(обязательное)`, ниже название;
  тип и название при этом полужирные (особенность шаблона).
- В содержании — `Приложение А (обязательное) Название`.
- На приложение можно ссылаться: `@listing` → «Приложение Б»,
  `@listing[приложении]` → «приложении Б».
- Внутри приложения рисунки/таблицы/формулы нумеруются `А.1`, `А.2`, `(А.1)`.

Ограничения:

- заголовки Typst внутри приложения не сбрасывают счётчик разделов и дают
  неверные номера (`2.1`, `3`, ...) — не используйте `=`, `==`, `===` внутри;
- после первого приложения все последующие рисунки/таблицы/формулы считаются
  «приложенческими» — приложения должны идти последними;
- буквы берутся из `appendix-letters` = `АБВГДЕЖИКЛМНПРСТУФХЦШЩЭЮЯ`
  (исключены Ё, З, Й, О, Ч, Ъ, Ы, Ь).

### `abclist(..items)`

Двухуровневый буквенный список (`а)`, `б)`, ...). Каждый аргумент — элемент
списка (контент). Внутри элемента можно писать `+`-список — он станет
`1)`, `2)`, ... с отступом 25 мм.

```typst
#abclist[
  Первый элемент;
][
  Второй элемент:
  + Вложенный пункт;
  + Ещё один;
][
  Третий элемент.
]
```

- Пунктуацию (`;`, `.`, `:`) пишет автор — функция её не добавляет.
- После каждого элемента добавляется пустая строка.
- Ссылки на элементы перечисления не поддерживаются (TODO пакета).
- Буквы: `абвгдежиклмнпрстуфхцчшщэюя` (без ё, з, й, о, ъ, ы, ь; `ч` есть —
  для перечислений из 2.3.8 исключений нет).

### `explanation(terms, supplement: [где])`

Перечень расшифровок после формулы. Принимает Typst term list:

```typst
#explanation[
  / 1,2: коэффициент, учитывающий момент инерции редуктора;
  / $J_"дв"$: момент инерции двигателя, $"кг" dot м^2$;
  / $epsilon_"дв"$: ускорение вала двигателя, $с^(-2)$.
]
```

Печатает `где` и выравнивает символы по тире. `supplement:` принимает
`[где]` по умолчанию, иной контент (например, `[Здесь]`) или `none` — без
слова, каждый символ отдельным абзацем.

### `source-text(path, name)`

Листинг содержимого файла: отображаемое имя + `raw`-блок.

```typst
#source-text(
  path("sections/program.py"),
  "program.py",
)
```

- Первый аргумент **обязательно** оборачивать в `path(...)`, иначе Typst
  ищет файл относительно пакета.
- Читает файл во время компиляции; путь — относительно файла, в котором
  вызвана функция.
- Обрезает ведущие и завершающие переводы строк.

## 3. Экспортируемые константы

| Имя | Значение / смысл |
| --- | --- |
| `font-size` | `14pt` |
| `main-font` | `"Times New Roman"` |
| `source-text-font` | `"Courier New"` |
| `line-height` | `18pt` |
| `right-leading` | `line-height - font-size` = `4pt` |
| `cyr-letters` | строчные буквы для `abclist` и `abc-images` |
| `appendix-counter` | счётчик приложений |
| `appendix-alphabet` | буквы приложений: без Ё, З, Й, О, Ч, Ъ, Ы, Ь (п. 2.7.2) |
| `appendix-letters` | допустимые буквы приложений |

Константы экспортируются, но `template` использует их значения на момент
вызова. Документы, создаваемые со skill, не должны переопределять правила
оформления после `#show: template`; при необходимости изменения обсуждают
минимальную правку пакета.

## 4. Что уже делает `template` (не дублируйте)

### Текст и страница

- `set text`: Times New Roman 14pt, `top-edge: 0.70em`, `bottom-edge: -0.3em`,
  переносы, `lang: "ru"`, `orphan: 0%`, `widow: 0%`.
- `set page`: A4, поля 2 / 2 / 1.5 / 3 см, нумерация `1`, номер внизу справа
  (`dy: -1cm + right-leading`, т. е. 10 мм от края).
- `set par`: по ширине, `leading: 4pt`, `spacing: 4pt`,
  `first-line-indent: (amount: 1.25cm, all: true)`.
- `set pagebreak(weak: true)` — перед первым разделом нет пустой страницы.

### Заголовки

- `set heading`: нумерация `1.1.1.1`, закладки, в содержании.
- Полужирный, Times New Roman 14pt, без переносов.
- Перед заголовком — пустая строка; после заголовков уровней 1–2 — ещё одна.
- Нумерованные заголовки — с отступом 1.25 см; ненумерованные — без отступа.
- Уровень 1: сброс счётчиков рисунков/таблиц/формул, разрыв страницы,
  `upper(it)` (в тексте ПРОПИСНЫМИ, в содержании — как написано).
- Уровень 1 без номера: по центру.
- Уровень 3 без текста: только номер пункта.
- Уровень 3 с текстом: попадает в содержание.
- Уровень 4: печатает **только номер**; текст заголовка шаблон
  отбрасывает (особенность show-rule). Подпункты оформляйте без названия.

### Списки

- `set list`: tight, маркер `--`; show-rule превращает элемент в абзац
  `– текст`.
- `set enum`: нумерация `1`, `2`, ...; show-rule печатает каждый элемент
  отдельным абзацем с номером.
- Вложенные `-`-списки **теряются** (см. `references/recipes.md`).

### Содержание

- `set outline`: без своего заголовка, глубина 3, отступ 1em.
- Show-rule добавляет `СОДЕРЖАНИЕ` (по центру, полужирное) и пустую строку.
- Записи содержания — без переносов.

### Рисунки

- Нумерация `раздел.номер`; в приложении — `А.номер`.
- Подпись снизу, supplement «Рисунок», separator `–`, gap 22pt.
- Пустая строка до и после рисунка.
- Без `caption` рисунок собирается, но подписи нет (нарушение СТП).

### Таблицы

- Подпись сверху, слева, supplement «Таблица», separator `–`, gap 1em.
- Show-rule пересобирает таблицу: добавляет шапку с названием таблицы,
  при продолжении печатает `Продолжение таблицы X` и повторяет шапку.
- `table.header(repeat: true)`.
- Запрет разрыва ячеек, разрешён разрыв таблицы.
- Штрих 0.75pt, вставки, выравнивание шапки по центру, ячеек — по левому
  краю.
- **Таблица без `caption` вызывает ошибку компиляции.**

### Формулы

- Нумерация `(раздел.номер)`; в приложении `(А.номер)`.
- Номер справа внизу (`number-align: right + bottom`).
- Шрифт `TeX Gyre Termes Math`.
- Пустые строки до и после блочной формулы.
- Десятичная точка заменяется на запятую (`1.5` → `1,5`) — только для чисел
  вида `целое.дробное` внутри `$...$`.
- `supplement` уравнения — «Уравнение»; ссылка `@eq` даёт
  «Уравнение (1.1)», `@eq[]` — «(1.1)».
- Typst курсивит латинские и строчные греческие буквы. СТП 2.4.2 требует
  прямой шрифт для русских и греческих; шаблон это не исправляет. При
  необходимости пишите `upright(beta)` (точечно) — но не переделывайте все
  формулы без запроса.

### Сноски

- Нумерация `1)`.
- Текст сноски — с абзацным отступом 1.25 см, размер 14pt.

### Библиография

- `set bibliography(title: none, style: "gost-7-1-2003.csl")`.
- Show-rule добавляет заголовок `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`,
  скрывает стандартную вёрстку, собирает источники и печатает их абзацами
  `[n] описание`.
- Стиль `gost-7-1-2003.csl` рассчитан на Hayagriva (`.yml`); правила ввода,
  известные пределы и проверка: `references/bibliography.md`. В версии 0.2.1
  месяц в дате газеты выходит в именительном падеже («5 март»); в обновлённом CSL
  (месяцы в родительном падеже) выходит «5 марта». При штатном CSL для газет
  указывайте только год.

### Прочее

- `show raw`: Courier New; после блочного `raw` — пустая строка.
- Приложения: разрыв страницы перед каждым.
- `set math.equation`, `show math.equation`: см. выше.

## 5. Версии

| Версия | Отличия |
| --- | --- |
| `0.1.0`, `0.1.1` | старые версии, не использовать для новых документов |
| `0.2.0` | предыдущая версия пакета |
| `0.2.1` | актуальная: `abc-images` — grid рисунков с нумерацией `а`, `б`; `figure-sheet(sheet, body)` для продолжения рисунка; `explanation(terms, supplement: [где])`; нумерация пунктов в пределах раздела без подразделов (п. 2.2.4); правки размеров, интерлиньяжа и содержания; из букв приложений убрана `Ч` (п. 2.7.2) |

Если проект уже использует другую версию, не меняйте её без необходимости:
номера рисунков/таблиц/формул и вёрстка могут отличаться.

## 6. Локальная установка и проверка

Обычно пакет уже установлен в Typst Universe. Для локальной версии:

```bash
mkdir -p ~/.local/share/typst/packages/preview/typo-stp
ln -s /path/to/typstp/typo-stp/0.2.1 ~/.local/share/typst/packages/preview/typo-stp/0.2.1
```

Либо без установки, через временный каталог пакетов:

```bash
mkdir -p /tmp/typst-packages/preview/typo-stp
ln -s /path/to/typstp/typo-stp/0.2.1 /tmp/typst-packages/preview/typo-stp/0.2.1
typst compile --package-path /tmp/typst-packages main.typ
```

Проверка шрифтов:

```bash
typst fonts | grep -Ei "times new roman|courier new|termes"
```

Нужны `Times New Roman`, `Courier New`, `TeX Gyre Termes Math`. Если их нет,
Typst подставит fallback — вёрстка будет отличаться от требований СТП.
