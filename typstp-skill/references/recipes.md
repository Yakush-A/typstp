# Рецепты для `typo-stp`

Все фрагменты проверены на `typo-stp 0.2.0` / Typst 0.15.1.
Скопируйте нужный блок в документ и замените текст.

---

## 1. Новый документ

```typst
#import "@preview/typo-stp:0.2.0": *

#show: template

#outline()

#introduction
Текст введения.

= Название первого раздела

== Название подраздела

===
Текст пункта без заголовка.

=== Пункт с заголовком
Текст пункта с заголовком.
```

Структура проекта:

```text
project/
├── main.typ          # import + show: template + outline + include
├── sections/
│   ├── 01-analysis.typ
│   └── 02-design.typ
├── img/
├── sources.yml
└── main.pdf
```

`main.typ`:

```typst
#import "@preview/typo-stp:0.2.0": *
#show: template

#outline()

#introduction
#lorem(120)

#include "sections/01-analysis.typ"
#include "sections/02-design.typ"

#bibliography("sources.yml")

#appendix("обязательное", "Листинг программы") <listing>
#source-text(path("sections/program.py"), "program.py")
```

В включаемых файлах — только разметка, без `#import` пакета и без
`#show: template`.

## 2. Разделы, подразделы, пункты

```typst
= Анализ предметной области      // 1 ПРОПИСНЫМИ, с новой страницы, в содержании
== Обзор существующих решений    // 1.1, полужирный, с прописной
===                              // 1.1.1, только номер, без заголовка
Текст пункта.

=== Методика расчёта             // 1.1.2, с заголовком, попадёт в содержание
Текст пункта.

====                             // 1.1.2.1, только номер, без заголовка
Текст подпункта.
```

Правила:

- Исходный текст заголовка пишите обычным регистром. `= Введение` →
  в документе `ВВЕДЕНИЕ`, в содержании `Введение`.
- Не добавляйте `#upper`, `*`, `#align(center)` — шаблон сделает сам.
- Точку в конце заголовка не ставьте.
- Пункт без заголовка — пустой `===`.
- Подпункт `====` печатает только номер: текст заголовка уровня 4 шаблон
  не выводит.
- Не используйте заголовки внутри приложений.

## 3. Перечисления

### 3.1. Простое (`–`, точка с запятой)

```typst
В состав устройства входят следующие блоки:
- датчик расстояния;
- фотодиодная матрица размером 32×32 элемента;
- задающий генератор.
```

Маркер `–` и абзацный отступ добавляет шаблон. Пунктуацию (`;`, `.`)
пишите сами.

### 3.2. Сложное (нумерованное)

```typst
1 Вычисляем Z-преобразование передаточной функции.
2 Определяем показатели качества.
3 Выбираем корректирующее устройство.
```

или разметкой списка:

```typst
+ Вычисляем Z-преобразование передаточной функции.
+ Определяем показатели качества.
+ Выбираем корректирующее устройство.
```

Шаблон печатает `1`, `2`, ... без точки; точку в конце предложения ставит
автор.

### 3.3. Продолжение нумерованного списка

Новый блок `+` после пустой строки начинается с `1`. Чтобы продолжить,
задайте первый номер явно:

```typst
+ Первый пункт;
+ Второй пункт;
+ Третий пункт.

4. Четвёртый пункт;
+ Пятый пункт;
+ Шестой пункт.
```

### 3.4. Буквенный список `#abclist`

```typst
#abclist[
  Первый элемент;
][
  Второй элемент:
  + Вложенный пункт;
  + Ещё один вложенный пункт;
][
  Третий элемент.
]
```

Получится:

```text
а) Первый элемент;
б) Второй элемент:
   1) Вложенный пункт;
   2) Ещё один вложенный пункт;
в) Третий элемент.
```

- Каждый аргумент — отдельный элемент.
- Вложенные `+` дают `1)`, `2)`.
- Ссылки на элементы не поддерживаются: пишите «в соответствии с пунктом
  1.7, б» вручную.
- Не вкладывайте `-`-списки: они теряются.

## 4. Рисунки

```typst
#figure(
  image("img/scheme.png", width: 75%),
  caption: [Структурная схема системы],
) <scheme>

В соответствии с рисунком @scheme[] ...
```

- `caption` обязателен по СТП (иначе подписи не будет).
- `width` подбирайте под рекомендации 92 × 150 или 150 × 240 мм.
- Подпись ставится снизу автоматически: `Рисунок 1.1 – Структурная схема`.
- Нумерация — по разделу; в приложении — `Рисунок А.1`.

Ссылки:

| Код | Результат |
| --- | --- |
| `@scheme` | `Рисунок 1.1` |
| `@scheme[]` | `1.1` |
| `на рисунке @scheme[]` | `на рисунке 1.1` |
| `в соответствии с рисунком @scheme[]` | `в соответствии с рисунком 1.1` |

Не пишите `на рисунке @scheme` — получится «на рисунке Рисунок 1.1».

Несколько рисунков в ряд. В 0.2.0 это два отдельных рисунка (`1.1`, `1.2`);
буквы `а`, `б` под рисунками даёт только `abc-images` из ветки 0.2.1:

```typst
#grid(
  columns: 2,
  column-gutter: 1em,
  figure(image("img/a.png", width: 100%), caption: [Схема а]),
  figure(image("img/b.png", width: 100%), caption: [Схема б]),
)
```

## 5. Таблицы

### 5.1. Базовая таблица

```typst
#figure(
  caption: [Результаты измерений],
  table(
    columns: (auto, 1fr, 1fr),
    table.header(
      [Наименование показателя],
      [Значение, В],
      [Погрешность, %],
    ),
    [Напряжение питания], [5,0], [1,5],
    [Ток потребления], [0,12], [2,0],
  ),
) <measurements>
```

- `caption` **обязателен**: без него ошибка
  `cannot access fields on type none`.
- Заголовок печатается слева сверху: `Таблица 1.1 – Результаты измерений`.
- Шапка повторяется при переносе, над продолжением появляется
  `Продолжение таблицы 1.1`.
- Не добавляйте графу «№ п/п».

Ссылки: `@measurements` → `Таблица 1.1`; `@measurements[]` → `1.1`;
`в таблице @measurements[]` → `в таблице 1.1`.

### 5.2. Длинная таблица

Просто добавьте строки. Разрыв и продолжение шаблон сделает сам:

```typst
#figure(
  caption: [Длинная таблица],
  table(
    columns: (auto, 1fr),
    table.header([Параметр], [Значение]),
    ..range(40).map(i => ([Параметр #i], [#i])).flatten(),
  ),
)
```

### 5.3. Примечание к таблице

Примечание к отдельным строкам/графам — последней строкой внутри таблицы,
над нижней чертой:

```typst
#figure(
  caption: [Значения коэффициента],
  table(
    columns: (auto, 1fr, 1fr),
    table.header([Показатель], [Вариант 1], [Вариант 2]),
    [Ошибка, угл. мин], [2,0], [(3,2)],
    [Время, с], [0,10], [0,11],
    table.cell(colspan: 3)[
      Примечание -- данные в скобках не соответствуют требованиям.
    ],
  ),
)
```

Для примечания после таблицы (не внутри):

```typst
#par(first-line-indent: 1.25cm)[
  Примечание -- текст примечания.
]
```

Несколько примечаний нумеруйте: `1 Примечание -- ...`, `2 Примечание -- ...`.

### 5.4. Таблица без шапки

Технически работает, но при переносе продолжение будет без заголовков граф.
По СТП лучше всегда делать `table.header(...)` (или нумерацию граф).

## 6. Формулы

### 6.1. Нумерованная формула

```typst
Момент инерции вычисляем по формуле

$ M_"дин" = (1.2 J_"дв" + J_"мх") epsilon_"дв", $ <moment>

#explanation[
  / 1,2: коэффициент, учитывающий приведенный момент инерции редуктора;
  / $J_"дв"$: момент инерции двигателя, $"кг" dot м^2$;
  / $J_"мх"$: приведенный к валу двигателя момент инерции механизма, $"кг" dot м^2$;
  / $epsilon_"дв"$: ускорение вала двигателя, $с^(-2)$.
]

Подставляя выражение @moment[] в уравнение @moment[], получаем...
```

- Номер `(1.1)` ставится справа автоматически.
- `1.2` в формуле автоматически станет `1,2`.
- Десятичный разделитель в тексте (вне формул) шаблон не меняет.
- `#explanation` печатает «где» и выравнивает символы.
- Ссылка: `@moment` → `Уравнение (1.1)`; `@moment[]` → `(1.1)`.
  По СТП пишите «в формуле @moment[]», а не просто `@moment`.

### 6.2. Несколько коротких формул в строке

```typst
$ x_1 = X - beta Y + beta^2 U ; #h(1cm) x_2 = Y - beta U $
```

### 6.3. Многострочная формула

```typst
$ 1 / pi = 10 sum_(k=0)^infinity frac(
    (-1)^k (6k)! (54510134 k + 13591409),
    (3k)! (k!)^3 (640320)^(3k + 3/2)
  ) + \
  + sum_(k=0)^infinity frac(
    (-1)^k (6k)! (54510134 k + 13591409),
    (3k)! (k!)^3 (640320)^(3k + 3/2)
  ) $
```

Номер при переносе встанет справа от последней строки.

### 6.4. Формула в приложении

```typst
#appendix("обязательное", "Расчётные формулы")
$ y = a x + b $ <appendix-eq>
```

Номер будет `(А.1)`.

## 7. Приложения и листинги

```typst
#appendix("обязательное", "Листинг программы") <listing>

Текст приложения. Листинг представлен в @listing[приложении].

#source-text(
  path("sections/program.py"),
  "program.py",
)
```

- Первый аргумент `#source-text` — обязательно `path("...")`.
- Второй — отображаемое имя (может отличаться от имени файла).
- Приложение начинается с новой страницы.
- Внутри приложения не используйте заголовки.
- Рисунки/таблицы/формулы в приложении получат `А.1`, `А.2`, `(А.1)`.

Ссылки на приложение:

| Код | Результат |
| --- | --- |
| `@listing` | `Приложение Б` |
| `@listing[приложении]` | `приложении Б` |
| `в @listing[приложении]` | `в приложении Б` |

## 8. Библиография

### 8.1. Hayagriva (`sources.yml`)

```typst
#bibliography("sources.yml")
```

```yaml
guk:
  type: book
  title: Процессоры Pentium II, Pentium Pro и просто Pentium
  author: "Гук, Михаил"
  publisher: {name: Питер Ком, location: СПб.}
  date: 1999
  page-total: 288
```

Цитирование:

```typst
... по данным Гука #cite(<guk>).
... по данным Гука @guk.
```

Оба варианта дают `[1]`. Нумерация — по порядку первого упоминания.

### 8.2. BibLaTeX (`sources.bib`)

```typst
#bibliography("sources.bib")
```

Стиль `gost-7-1-2003.csl` применяется и к `.bib`, но проверяйте вывод:
стиль экспериментальный.

### 8.3. Ручной список (если CSL не подходит)

```typst
#heading(numbering: none)[Список использованных источников]

#par(first-line-indent: 1.25cm)[
  [1] Гук, М. Процессоры Pentium II, Pentium Pro и просто Pentium /
  М. Гук. – СПб. : Питер Ком, 1999. – 288 с.
]
```

Заголовок сам станет `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ` по центру и начнёт
новую страницу. Не используйте одновременно `#bibliography` и ручной
заголовок.

## 9. Сноски и примечания

```typst
Текст со сноской#footnote[Пояснение к тексту.].
```

Нумерация `1)` и оформление внизу страницы уже настроены.

Примечание после материала:

```typst
#par(first-line-indent: 1.25cm)[
  Примечание -- текст примечания.
]
```

Несколько примечаний:

```typst
#par(first-line-indent: 1.25cm)[1 Примечание -- первое.]
#par(first-line-indent: 1.25cm)[2 Примечание -- второе.]
```

## 10. Титульный лист, реферат, нумерация страниц

Пакет не генерирует титульный лист и лист задания. Готовый макет
титульного листа — `assets/title-page.typ`; проверьте его по приложению В
СТП и подставьте свои данные.

Порядок в `main.typ`:

```typst
#import "@preview/typo-stp:0.2.0": *
#show: template

// Скрыть номера на первых трёх страницах (титул + оборот + реферат).
// Если страниц больше/меньше — измените число.
#set page(footer: context {
  let p = counter(page).get().first()
  if p > 3 {
    place(bottom + right, dy: -1cm, str(p))
  }
})

#include "title-page.typ"

#pagebreak()
#heading(numbering: none)[Реферат]
Текст реферата (850–1200 знаков).

#pagebreak()
#outline()

#introduction
...
```

- Титульный лист и реферат входят в общую нумерацию, но номер не печатается.
- `#heading(numbering: none)` даёт центрированный прописной заголовок.
- Если вставляете скан задания, добавьте его отдельной страницей и увеличьте
  порог в `p > 3`.

## 11. Проверенные подводные камни

| Симптом | Причина | Что делать |
| --- | --- | --- |
| `Рисунок 0.1`, `Таблица 0.1`, `(0.1)` | элемент стоит до первого нумерованного раздела (введение, реферат) | перенесите рисунок/таблицу/формулу в первый раздел; счётчик разделов в этих частях равен 0 |
| `cannot access fields on type none` | у `#figure` с таблицей нет `caption` | добавьте `caption: [...]` |
| Вложенные `-` пункты исчезли | show-rule списка превращает элемент в абзац | используйте `#abclist` для двух уровней |
| Нумерованный список после пустой строки начался с `1` | show-rule нумерации берёт начало блока | начните блок явным номером: `4. ...` |
| Заголовок внутри приложения получил номер `2.1` / `3` | счётчик разделов не сбрасывается на приложении | не используйте `=`, `==`, `===` внутри приложения |
| У подпункта `==== Название` пропал текст | show-rule уровня 4 печатает только номер | оформляйте подпункт без названия (`====`), текст — следующим абзацем |
| «на рисунке Рисунок 1.1» | `@label` подставляет supplement | пишите `на рисунке @label[]` |
| «в формуле Уравнение (1.1)» | у уравнения supplement «Уравнение» | пишите `в формуле @label[]` |
| Два «СОДЕРЖАНИЕ» / два «СПИСОК...» | заголовок добавлен вручную | уберите ручной заголовок: шаблон добавляет его сам |
| `file not found` в `#source-text` | путь ищется относительно пакета | оберните путь в `path("...")` |
| Ошибка после добавления приложения | приложение стоит не последним, либо внутри есть заголовки | ставьте приложения в конец, без заголовков внутри |
| Ссылка на приложение не работает | метка не привязана к `#appendix` | пишите `<метка>` сразу после `#appendix(...)` |
| Нумерация сквозная не получается | шаблон сбрасывает счётчики в каждом разделе | сквозная нумерация не поддерживается; не ломайте шаблон без необходимости |
| Размер шрифта изменился не везде | заголовки задают `size: font-size` явно | меняйте оформление через `#show heading: ...`, а не только `#set text` |
| Таблица уже страницы, а подпись у края страницы | шаблон выравнивает подпись по странице | ограничение шаблона; для широких таблиц совпадает с СТП |

## 12. Быстрая проверка

```bash
# сборка
typst compile main.typ main.pdf

# список рисунков/таблиц и их меток
typst query main.typ "figure" | python3 -m json.tool | less

# все ссылки
typst query main.typ "ref" | python3 -m json.tool | less

# текст PDF: проверить нумерацию и подписи
pdftotext -layout main.pdf - | grep -nE "Рисунок|Таблица|Продолжение|ПРИЛОЖЕНИЕ|СПИСОК"
```

Готовый скрипт с автоматическими предупреждениями — `assets/check.sh`
(путь относительно каталога skill):

```bash
bash /path/to/typstp-skill/assets/check.sh main.typ
# с локальным пакетом:
bash /path/to/typstp-skill/assets/check.sh main.typ /tmp/typst-packages
```
