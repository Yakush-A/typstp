  с ГОСТ 7.1-2003 начиная с версии 0.2.0 пакета.

## Использование пакета
Для использования пакета достаточно импортировать его в основной файл и
применить show-рул. Пример:

```Typst
#import "@preview/typo-stp:[Версия]": *

show: template
```

show-рул нужен для установки общего форматирования, его нужно применять только
в основном файле проекта.

Для использования встроенных функций, можно импортировать только их:
```typst
#import "@preview/typo-stp:[Версия]": introduction, explanation

#introduction
Текст текст текст...

$ a + b + c = d $

#explanation[
  / a: текст текст текст;
  / b: текст текст;
  / c: текст текст текст;
  / d: текст текст текст текст;
]
```

Более детальные примеры с пояснениями можно посмотреть [здесь](./example), а
реальную оформленную работу (мой курсач)
[здесь](https://github.com/Yakush-A/esp32-gimbal/tree/main/report)

## Локальная установка пакета
Т.к. при публикации на Typst Universe рассмотрение пакета идет достаточно
долго, актуальные версии будут публиковаться в этом репозитории, а после 
на Universe. 
([Ссылка на актуальную версию пакета на Typst Universe](https://typst.app/universe/package/typo-stp))

Для локальной установки пакета Вам нужно склонировать данный репозиторий
и добавить каталог [typo-stp](./typo-stp) в путь локальных пакетов Typst на 
Вашей системе. [Подробнее](https://github.com/typst/packages#local-packages) 

Условно для Linux: 
```bash
git clone git@github.com:Yakush-A/typstp.git path/to/repo

mkdir -p ~/.local/share/typst/packages/preview

ln -s path/to/repo/typo-stp ~/.local/share/typst/packages/preview/typo-stp
```

Для проверки правильности установки попробуйте инициализировать актуальную
версию пакета (актуальную здесь, не на Typst Universe):

```bash
typst init @preview/typo-stp:[Актуальная версия из ./typo-stp] path/to/template
```

## Скилл для нейронок
В [typstp-skill](./typstp-skill) лежит скилл для данного шаблона. Он 
не окончательный, и в будущем может поменяться, но он работает и работает
достаточно неплохо для отчетов к лабам. 

### Содержание документа
Т.к. не все требования СТП являются чисто техническими, содержание конкретного
документа за исключением дипломов зависит от его типа. В связи с этим, нейронка
может не знать, какие Вам нужны разделы в том же отчете или курсовой - это
нужно описать в промпте. Пример:

```text
Напиши то-то то-то. 
Структура разделов должна быть следующая: Введение, Цели и задачи, , ...
или
Структуру разделов возьми из [документ в формате, который Ваш агент поймет].
```

### Про титульники, листы заданий
Шаблон на данный момент не поставляет титульных листов, листов заданий. 
Их скилл запретит генерить просто так. Если у Вас уже есть титульник и т.д. - 
укажите, где его взять и по возможности как правильно его вставить.

```
...
Титульник возьми из [любой другой Ваш отчет с данным шаблоном].
```

В скилле есть некий линт по орфографии, нумерации разделов, формулировкам, 
но он навайбкожен (как и у 
[bsuir_typst](https://github.com/artemious3/bsuir_typst) :) ). 

### Про нюансы с подключением
Как подключить скилл я думаю, Вы уже разберетесь сами для своего инструмента,
Единственное, если Вы будете пользоваться им из чатботов по типу Клода, им
нужны шрифты Times New Roman, Tex Gyre Math, Courier New, которые в связи с 
их лицензиями я разместить здесь не могу.

В общем, если у Вас есть какие-то идеи по улучшению скилла - я только за.
