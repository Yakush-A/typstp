## Использование пакета
Для использования пакета достаточно импортировать его в основной файл и
применить show-рул. Пример:

```typst
#import "@preview/typo-stp:[Версия]": *

show: template
```

show-рул нужен для установки общего форматирования, его нужно применять только
в основном файле проекта.

Для использования встроенных функций, можно импортировать только их:
```typst
#import "@preview/typo-stp:[Версия]": introduction, explanation

#introduction
Текст текст текст...

$ a + b + c = d $

#explanation[
  / a: текст текст текст;
  / b: текст текст;
  / c: текст текст текст;
  / d: текст текст текст текст;
]
```

Более детальные примеры с пояснениями можно посмотреть [здесь](./example), а
реальную оформленную работу (мой курсач)
[здесь](https://github.com/Yakush-A/esp32-gimbal/tree/main/report)


## Локальная установка пакета
Т.к. при публикации на Typst Universe рассмотрение пакета идет достаточно
долго, актуальные версии будут публиковаться в этом репозитории, а после 
на Universe. 
([Ссылка на актуальную версию пакета на Typst Universe](https://typst.app/universe/package/typo-stp))

Для локальной установки пакета Вам нужно склонировать данный репозиторий
и добавить каталог [typo-stp](./typo-stp) в путь локальных пакетов Typst на 
Вашей системе. [Подробнее](https://github.com/typst/packages#local-packages) 

Условно для Linux: 
```bash
git clone git@github.com:Yakush-A/typstp.git path/to/repo

mkdir -p ~/.local/share/typst/packages/preview

ln -s path/to/repo/typo-stp ~/.local/share/typst/packages/preview/typo-stp
```

Для проверки правильности установки попробуйте инициализировать актуальную
версию пакета (актуальную здесь, не на Typst Universe):

```
typst init @preview/typo-stp:[Актуальная версия из ./typo-stp] path/to/template
```
